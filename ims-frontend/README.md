# Inventory Management System (IMS)

A robust and modern web application designed to streamline inventory tracking, product management, and transaction recording. This system provides a seamless interface for businesses to manage their stock efficiently.

## 🚀 Key Features

*   **Dashboard**: Get a high-level overview of your inventory status and recent activities.
*   **Product Management**: flexible system to add, update, and categorize products.
*   **Inventory Tracking**: Real-time monitoring of stock levels.
*   **Transaction Recording**:
    *   **Inbound**: Record stock arrivals and purchases.
    *   **Outbound**: Track sales and stock usage.
*   **Modern UI/UX**: Built with **Angular Material** and **Tailwind CSS** for a responsive and intuitive experience.
*   **Robust Validation**: Ensures data integrity for transaction quantities and product details.

## 🛠️ Tech Stack

This project is built using the latest web technologies to ensure performance and scalability.

**Frontend:**
*   **[Angular](https://angular.io/) v21** - Core framework.
*   **[Angular Material](https://material.angular.io/)** - UI Component library.
*   **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework for styling.
*   **TypeScript** - Strictly typed JavaScript.

**Backend (Integration):**
*   **Spring Boot** (Java)

## ⚙️ Getting Started

### Prerequisites

*   **Node.js**: Ensure you have a compatible version installed (v18+ recommended).
*   **npm**: Comes with Node.js.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/ims-frontend.git
    cd ims-frontend
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

### Development Server

Run the application locally:

```bash
ng serve
```

Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

### Build

To build the project for production:

```bash
ng build
```
The build artifacts will be stored in the `dist/` directory.

### Running Tests

To execute unit tests:

```bash
ng test
```
